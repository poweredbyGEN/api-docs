The Content Ideas API generates video content ideas by analyzing trending videos with engagement-weighted hooks and transcripts. Ideas include hooks, scripts, scene breakdowns, and inspiration sources with real creator data.

**Base URL:** `https://agent.gen.pro/v1` (same API key as the main API)

## Quick Start

### 1. Generate Ideas

```bash
curl -X POST https://agent.gen.pro/v1/agent/run \
  -H "X-API-Key: $GEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "generate 5 content ideas focused on before/after transformations, keep under 12 seconds",
    "agent_id": "YOUR_AGENT_ID"
  }'
```

**Response (202):**
```json
{
  "run_id": "abc-123",
  "conversation_id": "def-456",
  "status": "running",
  "progress_stream_url": "..."
}
```

### 2. Poll for Completion

```bash
curl https://agent.gen.pro/v1/agent/runs/abc-123 \
  -H "X-API-Key: $GEN_API_KEY"
```

Poll every 5 seconds until `status` is `"completed"`. The `messages` array contains the generated ideas.

### 3. Refine Ideas

```bash
curl -X POST https://agent.gen.pro/v1/agent/run \
  -H "X-API-Key: $GEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "make idea 1 hook shorter and punchier. change idea 3 to montage format.",
    "conversation_id": "def-456",
    "agent_id": "YOUR_AGENT_ID"
  }'
```

Pass the `conversation_id` from step 1 to refine in context.

## Three Layers of Control

| Layer | Scope | Example |
|-------|-------|---------|
| **Per-batch requirements** | This generation only | "focus on before/after", "under 12 seconds" |
| **Long-term preferences** | ALL future generations | "always use statement hooks", "target women 25-34" |
| **Feedback/refinement** | Specific ideas | "make idea 3 punchier", "redo 2 and 4 as montage" |

### Setting Persistent Preferences

```bash
curl -X POST https://agent.gen.pro/v1/agent/run \
  -H "X-API-Key: $GEN_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "message": "remember: always use statement hooks, never questions. target women 25-34.",
    "agent_id": "YOUR_AGENT_ID"
  }'
```

Preferences are stored in the agent's config and applied to every future generation.

## Idea Status Lifecycle

```
generated → approve_to_create → ready_for_review → approved_to_post → posted
```

Use `change_idea`, `change_video`, or `rejected` when an idea needs edits or should not move forward.

### List Ideas

```bash
curl "https://agent.gen.pro/v1/agent/ideas?agent_id=YOUR_AGENT_ID&status=generated" \
  -H "X-API-Key: $GEN_API_KEY"
```

### Update Status

```bash
curl -X PUT "https://agent.gen.pro/v1/agent/ideas/123/status/approve_to_create" \
  -H "X-API-Key: $GEN_API_KEY"
```

## Real-Time Progress

The `progress_stream_url` from the run response is an opaque, run-specific
progress channel (treat it as sensitive — it's scoped to that one run). It
streams:

- `status` — "running", "completed", or "failed"
- `plan` — numbered checklist of what the agent is doing
- `thinking` — progress messages
- `messages` — output when complete

If you'd rather not consume the stream, poll `GET /v1/agent/runs/{run_id}`
with your API key until `status` is `"completed"`.

## MCP Server

Content ideas go through the `gen_content_action` dispatcher (`actions[]`) plus the `gen_discover` reads. The per-endpoint tool names are retired:

| Call | Purpose |
|------|---------|
| `gen_content_action` action `generate_ideas` | Generate ideas with optional requirements and video type filter; reply to `needs_input` / `proposal` with `feedback`, or `confirm: true` to start the job |
| `gen_content_action` action `generate_ideas` with `from_ideas` + `feedback` | Refine ideas in conversation context (replaces the retired `gen_refine_content_ideas`) |
| `gen_content_action` action `set_content_preference` | Set persistent generation rules |
| `gen_content_action` action `set_idea_status` | Move an idea through `generated` / `approve_to_create` / `ready_for_review` / `rejected` / `posted` (replaces the retired `gen_update_idea_status`) |
| `gen_discover` domain=content view=idea_job | Poll the returned `job_id` (replaces the retired `gen_get_run_status`) |
| `gen_discover` domain=content view=ideas | List ideas with an optional status filter (replaces the retired `gen_list_content_ideas`) |
