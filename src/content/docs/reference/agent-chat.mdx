The Agent Chat API provides conversational AI for content creation. Generate ideas, refine them, set preferences, and manage conversations.

**Base URL:** `https://agent.gen.pro/v1`

## Authentication

Same as the main API — pass your API key in the `X-API-Key` header. JWT authentication (`Authorization: Bearer <token>`) is also supported for frontend integrations.

## Runs

### POST /v1/agent/run

Start an agent run (generate ideas, refine, chat).

**Request:**
```json
{
  "message": "generate 5 content ideas",
  "agent_id": "uuid",
  "conversation_id": "uuid (optional — continue conversation)",
  "attachments": [
    {
      "signed_id": "string",
      "filename": "string",
      "content_type": "string",
      "url": "string"
    }
  ],
  "context": {"vidsheet_id": 123},
  "debug": false
}
```

**Response (202):**
```json
{
  "run_id": "uuid",
  "conversation_id": "uuid",
  "status": "running",
  "progress_stream_url": "..."
}
```

When the conversation already has a run in flight the message is queued behind it and the call answers HTTP 202 without a `run_id`:

```json
{
  "queued": true,
  "pending_id": "uuid",
  "status": "queued",
  "position": 1,
  "active_run_id": "uuid",
  "conversation_id": "uuid"
}
```

`mode` selects how a continuation is sent: `queue` (default) queues behind the live run, `steer` injects the message into that run. `client_message_id` (max 64 characters) is an idempotency key — a retry with the same key reuses the queued row. A conversation holds 10 queued messages; the next is refused with HTTP 409 and `error_code: "queue_full"`.

### GET /v1/agent/runs/:run_id

Poll run status. Poll every 5 seconds until `status` is `"completed"`.

**Response:**
```json
{
  "run_id": "uuid",
  "conversation_id": "uuid",
  "status": "running | completed | failed",
  "messages": [
    {"role": "assistant", "content": "..."}
  ]
}
```

### POST /v1/agent/runs/:run_id/approve

Approve or reject a pending action gate.

**Request:**
```json
{
  "approved": true
}
```

Use `{ "approved": false }` to reject the pending action.

### POST /v1/agent/runs/:run_id/stop

Stop a run and return its conversation's queued messages.

**Response:**
```json
{
  "run_id": "uuid",
  "status": "stopped",
  "returned": [
    {"pending_id": "uuid", "body": "add captions to the second clip"}
  ]
}
```

## Conversations

### GET /v1/agent/conversations

List conversations, newest first.

**Parameters:**
| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `agent_id` | string | No | Filter by agent |
| `limit` | integer | No | Maximum conversations to return (default 20) |
| `after` | string | No | Cursor: the `next_cursor` of the previous page |

Each row carries `has_active_run`, and the response carries `next_cursor` for the next page.

### GET /v1/agent/conversations/:id

Get a conversation with its messages. `limit` caps the messages returned (default 50) and `before` reads the page older than a message ID.

### GET /v1/agent/conversations/:id/pending

List the messages queued behind the conversation's live run.

**Response:**
```json
{
  "pending": [
    {
      "pending_id": "uuid",
      "body": "add captions to the second clip",
      "status": "queued",
      "position": 1,
      "created_at": "2026-04-03T10:30:00Z"
    }
  ]
}
```

### PATCH /v1/agent/conversations/:id/pending/:pending_id

Promote a queued message into the live run. `steering` is the only accepted status.

**Request:**
```json
{
  "status": "steering"
}
```

### DELETE /v1/agent/conversations/:id/pending/:pending_id

Cancel a queued message. A message that has already run is refused.

### GET /v1/agent/conversations/:id/messages

Paginated message history for a conversation.

### PATCH /v1/agent/conversations/:id

Rename or pin/unpin a conversation.

**Request:**
```json
{
  "title": "New title",
  "pinned": true
}
```

### DELETE /v1/agent/conversations/:id

Soft delete a conversation.

### GET /v1/agent/conversations/:id/runs

List all runs within a conversation.

## Content Ideas

### GET /v1/agent/ideas

List content ideas for an agent.

**Parameters:**
| Parameter | Required | Description |
|-----------|----------|-------------|
| `agent_id` | Yes | The agent ID |
| `status` | No | Filter: `generated`, `approve_to_create`, `ready_for_review`, `change_idea`, `change_video`, `rejected`, `approved_to_post`, `posted` |

**Response:**
```json
[
  {
    "id": 123,
    "idea_id": 1,
    "agent_id": "uuid",
    "title": "Before & After Glow Up",
    "hook": "Watch what happens in 7 days",
    "description": "Side-by-side transformation...",
    "video_type": "montage",
    "video_type_id": 3,
    "status": "generated",
    "data": {},
    "created_at": "2026-04-03T10:30:00Z"
  }
]
```

### POST /v1/agent/ideas/:id/status

Cycle an idea to its next status in the flow.

### PUT /v1/agent/ideas/:id/status/:status

Set an explicit status value.

**Status flow:**
```
generated → approve_to_create → ready_for_review → approved_to_post → posted
```

Ideas can also be moved to `change_idea`, `change_video`, or `rejected` when they need edits or should not move forward.

## Agent Profile

### GET /v1/agent/profile

Get the full unified agent profile (identity + voice + brand config).

**Parameters:** `agent_id` (query, required)

**Response:**
```json
{
  "identity": {
    "name": "Jordan Mathews",
    "description": "AI skincare content creator",
    "avatar_url": "https://cdn.gen.pro/avatar.jpg",
    "use_character": true,
    "persona": "Warm, knowledgeable friend"
  },
  "voice": {
    "eleven_lab_api_key": "...",
    "default_voice": {"id": "...", "name": "...", "provider": "eleven_labs"}
  },
  "brand": {
    "brand_name": "Jordan Skincare",
    "description": "Honest skincare reviews",
    "goal": "Grow TikTok to 100K",
    "keywords": ["sensitive skin", "skincare routine"],
    "target_platforms": ["tiktok", "instagram"],
    "linked_accounts": [{"handle": "@jordanskincare", "platform": "tiktok"}],
    "content_idea_preferences": "- always use statement hooks\n- target women 25-34",
    "onboarding_status": "complete"
  }
}
```

### POST /v1/agent/profile

Create or first-time setup of agent profile. Send any combination of `identity`, `voice`, and `brand` sections.

### PUT /v1/agent/profile

Update profile. Send only the fields you want to change. Array fields (`keywords`, `target_platforms`, `linked_accounts`) are replaced entirely, not appended.

### DELETE /v1/agent/profile

Reset the agent's brand config only. Agent identity and voice settings are preserved.

## Real-Time Progress

The `progress_stream_url` returned by `POST /v1/agent/run` is an opaque,
run-specific channel with real-time progress (treat it as sensitive — it's
scoped to that one run). Or poll `GET /v1/agent/runs/{run_id}` with your API
key for an authenticated status path. The channel streams:

| Key | Description |
|-----|-------------|
| `status` | `"running"`, `"completed"`, or `"failed"` |
| `plan` | Numbered checklist of agent steps |
| `thinking` | Progress/reasoning messages |
| `messages` | Final output when complete |
