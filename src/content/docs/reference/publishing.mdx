Publishing lets you connect social accounts and post content immediately or schedule it for later. Supported platforms: **TikTok, Instagram, Facebook, YouTube, and X**.

<Aside type="note">
  Publishing requires authentication via the `X-API-Key` header. Connect a social account first via the OAuth flow before posting.
</Aside>

## Connect a social account

### Get the OAuth URL

Returns a single-use OAuth URL the user opens in a browser to authorize GEN to post on their behalf. Never ask for credentials directly — always use this flow.

```
GET /platform/get_authorization_url
```

Base URL: `https://python.gen.pro`

#### Parameters

| Parameter | Type | Required | Description |
|-----------|------|----------|-------------|
| `agent_id` | string | Yes | The agent to attach the account to. |
| `platform` | string | Yes | `tiktok` \| `instagram` \| `facebook` \| `youtube` \| `x` |

#### Example

```bash
curl "https://python.gen.pro/platform/get_authorization_url?agent_id=your-agent-id&platform=tiktok" \
  -H "X-API-Key: your-api-key"
```

### List connected accounts

```
GET /platform/get_oauth_account?agent_id={agent_id}
```

Base URL: `https://python.gen.pro`

```bash
curl "https://python.gen.pro/platform/get_oauth_account?agent_id=your-agent-id" \
  -H "X-API-Key: your-api-key"
```

### Disconnect an account

```
PUT /platform/disconnect/:platform
```

Base URL: `https://python.gen.pro`

```bash
curl -X PUT "https://python.gen.pro/platform/disconnect/tiktok" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"agent_id": "your-agent-id"}'
```

## Schedule a post

```
POST /schedule/with-post
```

Base URL: `https://python.gen.pro`

### Fields

| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `agent_id` | string | Yes | The agent posting. |
| `platform` | string[] | Yes | Array with the target platform: `["tiktok"]`, `["instagram"]`, etc. |
| `schedule_type` | string | Yes | `now` (immediate) or `specific_time` (requires `scheduled_time`). |
| `description` | string | Conditional | Post caption. Required for text-only posts (X) or recommended for all. |
| `media_url` | string | No | Single video URL. |
| `media_urls` | string[] | No | Image URLs (X supports up to 4). |
| `title` | string | No | Post title (YouTube). |
| `media_type` | string | No | `VIDEO` (default) \| `IMAGE` \| `TWEET_VIDEO` |
| `scheduled_time` | string | Conditional | ISO 8601 datetime — required when `schedule_type` is `specific_time`. |
| `thumbnail_url` | string | No | Custom thumbnail URL. |
| `timezone_offset` | number | No | Local UTC offset in hours (e.g. `-7` for PDT). Omit to use the agent's configured timezone. |
| `thread` | object[] | No | **X only.** Ordered chain of tweets: `[{"text":"..."}, {"text":"...", "media_urls":["..."]}]` |
| `reply_to_tweet_id` | string | No | **X only.** Post as a reply to this tweet id. |

<Aside type="note">
  `thread` and `reply_to_tweet_id` apply to **X only**.
</Aside>

### Example: Post now (TikTok)

```bash
curl -X POST "https://python.gen.pro/schedule/with-post" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "your-agent-id",
    "platform": ["tiktok"],
    "description": "Factory price reveal #sourcing #china",
    "media_url": "https://cdn.example.com/video.mp4",
    "media_type": "VIDEO",
    "schedule_type": "now"
  }'
```

### Example: Scheduled post (Instagram)

```bash
curl -X POST "https://python.gen.pro/schedule/with-post" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "your-agent-id",
    "platform": ["instagram"],
    "description": "Morning routine 🌅 #wellness",
    "media_url": "https://cdn.example.com/video.mp4",
    "schedule_type": "specific_time",
    "scheduled_time": "2026-08-01T09:00:00Z"
  }'
```

### Example: X thread

```bash
curl -X POST "https://python.gen.pro/schedule/with-post" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{
    "agent_id": "your-agent-id",
    "platform": ["x"],
    "schedule_type": "now",
    "thread": [
      { "text": "1/ Our launch thread:" },
      { "text": "2/ Here is what we built", "media_urls": ["https://cdn.example.com/shot.jpg"] },
      { "text": "3/ Thanks for reading!" }
    ]
  }'
```

## Content calendar

### List scheduled posts

```
GET /schedule/posts?agent_id={agent_id}
```

Optional: `start_date` and `end_date` (ISO 8601) to filter the calendar window.

```bash
curl "https://python.gen.pro/schedule/posts?agent_id=your-agent-id&start_date=2026-08-01&end_date=2026-08-31" \
  -H "X-API-Key: your-api-key"
```

### Get post status

Check whether a post actually went live (not just queued). Returns platform-confirmed status.

```
GET /schedule/post/:post_id
```

```bash
curl "https://python.gen.pro/schedule/post/post-id-here" \
  -H "X-API-Key: your-api-key"
```

#### Response

```json
{
  "id": "post-id",
  "status": "published",
  "platforms": [
    {
      "platform": "tiktok",
      "status": "published",
      "platform_post_id": "7123456789",
      "post_url": "https://tiktok.com/@user/video/7123456789",
      "published_at": "2026-08-01T09:01:12Z",
      "error": null
    }
  ]
}
```

Overall status flow: `accepted` → `publishing` → `published` | `failed`.

### Update a scheduled post

Edit a post before it goes out. Only works on posts that have not yet been published.

```
PATCH /schedule/post/:post_id
```

```bash
curl -X PATCH "https://python.gen.pro/schedule/post/post-id-here" \
  -H "X-API-Key: your-api-key" \
  -H "Content-Type: application/json" \
  -d '{"scheduled_time": "2026-08-02T10:00:00Z"}'
```

### Delete a scheduled post

```
DELETE /schedule/post/:post_id
```

```bash
curl -X DELETE "https://python.gen.pro/schedule/post/post-id-here" \
  -H "X-API-Key: your-api-key"
```

## Errors

| Status | Error code | Description |
|--------|------------|-------------|
| `401` | `unauthorized` | Missing or invalid API key. |
| `403` | `permission_denied` | You do not have access to this agent. |
| `422` | `validation_error` | Invalid or missing required fields. |
| `422` | `insufficient_credits` | The agent's workspace has no usable credits. |
| `404` | `not_found` | The post or agent was not found. |
